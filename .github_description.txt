# CyberMind AI v2.0 - Autonomous Penetration Testing Agent

**For CTF/HackTheBox environments**

## What's New (v2.0)

✨ **Fully Autonomous Exploitation** - No user prompts needed
🔗 **Automatic Shell Retrieval** - Meterpreter, reverse shells, bind shells
📈 **Post-Exploitation Automation** - Privilege escalation, credential dumping
🧠 **AI-Powered Decision Making** - Uses Groq's Llama 3.3 70B model
📊 **Professional Reporting** - Auto-generated PDF reports with findings

## Quick Start

```bash
# Clone and setup
git clone <repo>
cd cybermind-ai
bash quickstart.sh

# Run autonomous pentest
python3 agent.py --target 10.10.10.40 --autonomous

# Results
# - Automatic reconnaissance
# - Automatic vulnerability scanning
# - Automatic exploit selection and execution
# - Automatic shell retrieval
# - Automatic post-exploitation
# - PDF report with findings
```
